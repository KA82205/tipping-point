Tipping Point · for whoever keeps the site

The Civiqs data file

Tipping Point takes the gaps in approval between states from Civiqs's tracker, which is refreshed by hand every few weeks. This page turns a saved copy of that tracker into a small file of figures and nothing else: one date, fifty states, fifty percentages.

It works inside this browser. The saved page is read here and is not sent anywhere; this page is not allowed to make a request at all, and it works with the network off.

  1. Get the tracker's source

    Open the tracker. Press Ctrl+U (on a Mac, Cmd+Option+U) to see its source, then Ctrl+S (Cmd+S) to save it anywhere on this computer.

  2. Give it to this page



    Or paste the source instead of saving it

    In the source tab: Ctrl+A, Ctrl+C. Then click in the box and press Ctrl+V.

  3. Send the data file to the inbox

    The file appears here once a saved page has been read.

    Read.

    Open GitHub with the file filled in Download the file instead

    On GitHub, press Commit changes twice. That is all: the site checks the figures, runs its models again, publishes, and tells The Margin, in about three minutes. If you downloaded the file instead, drop it on the inbox's upload page and commit.

Why not upload the saved page itself? A saved page carries everything Civiqs's site sends a browser: its scripts, its settings, and keys for the outside services its own site uses. None of that belongs in a public repository. GitHub's scanner reports such keys, and a file once committed stays in the repository's history even after it is deleted. The inbox no longer reads saved pages; it takes this data file only.
